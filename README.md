# Tanushri Ravindra More | Portfolio Website

A fast, lightweight, and modern personal portfolio website for **Tanushri Ravindra More** — Aspiring AI/ML Engineer, Future Entrepreneur, and B.Tech student in Artificial Intelligence and Machine Learning at **R.C. Patel Institute of Technology (RCPIT), Shirpur**.

Built with semantic HTML5, modern CSS3 (clean minimalist light theme with dark mode toggle), and vanilla JavaScript with zero build dependencies.

---

## 🌟 Key Features

- **Clean Minimalist Aesthetic**: Crisp typography (`Plus Jakarta Sans` & `JetBrains Mono`), comfortable contrast, and modern layout.
- **Light & Dark Mode**: Persistent theme switcher with CSS custom properties and `localStorage`.
- **Hero Showcase**: Monogram brand `<TRM/>`, impact headline, active status badge, CV download link, and profile card.
- **About Me**: Narrative bio, 3 core focus areas (AI/ML, Web Systems, Tech Entrepreneurship), and quick facts card.
- **Technical Skills**: Categorized into *AI & Machine Learning*, *Web Development*, *Databases & Backend Logic*, and *Tools & Innovation*.
- **Featured Projects**: Filterable project gallery featuring the *Smart Village Resource Sharing Portal*, *AI Agricultural Yield & Diagnostic System*, *Campus Connect*, and *Exploratory Data Analytics Engine*.
- **Journey Timeline**: Academic path at RCPIT Shirpur, project milestones, and student collaboration.
- **Interactive Contact Section**: Contact cards, 1-click clipboard email copy (`moretanushri05@gmail.com`), active links to GitHub & LinkedIn, and a client-side validated contact form.
- **Mobile Responsive**: Optimized across desktops, tablets, and smartphones with mobile drawer navigation.

## 🚀 How to Run & Preview Locally

### Option 1: Directly in Browser
Simply double-click [`index.html`](index.html) in Windows File Explorer to open it in Chrome, Edge, Firefox, or Brave.

### Option 2: Using Python Local Server
Run the following command in PowerShell inside this directory:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your web browser.

## 🌐 Free 1-Click Deployment to GitHub Pages

1. Push this folder to your GitHub repository at [github.com/Tanushrimore](https://github.com/Tanushrimore).
2. On GitHub, navigate to **Settings > Pages**.
3. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
4. Your website will be live worldwide at:
   ```text
   https://tanushrimore.github.io/<repo-name>/
   ```
